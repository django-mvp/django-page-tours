Django Page Tours

Guided tours of a page for Django sites, shown with Driver.js.

This is the demonstration project. It is not distributed with the package. It exists so the package can be seen in a browser while it is written, and so every kind of tour step has a page that shows it. Each feature adds its page here and a link in the bar above.

The tour page plays a tour the first time you open it.

The plays-once page plays its tour once and offers a button to play it again. The on-request page never plays its tour by itself; its two buttons do.
